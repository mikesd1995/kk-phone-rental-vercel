# V6.1 Conversion Polish — 2026-10-02

## Why
Production iPhone evidence and the V6 full storefront audit showed that the storefront was technically stable but still read more like a catalogue than a booking surface.

## Changes
- Added a compact commerce/trust strip before discovery controls: vivo X300 Pro starting price, free insurance, no deposit, event pickup/return, 30-day file retention.
- Promoted the event-card package affordance from low-emphasis text into a compact pill CTA without changing the card click behavior.
- Strengthened price/availability/CTA rhythm while preserving poster-first hierarchy.
- Moved the floating LINE contact control away from the left content rail on mobile.
- Added regression assertions for the new conversion hierarchy.

## Guardrails
No pricing computation, availability calculation, booking message, LINE destination, inventory, Admin, API, Apps Script, or production-write behavior is changed.
