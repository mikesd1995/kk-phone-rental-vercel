## Observed failures

The partial survey on 14 October discovered the official One Bangkok Gong Yoo page with an observed event title and URL but unknown date/time/venue. Three independent boundaries prevented hydration: the public-detail capability did not support One Bangkok; the generic page parser did not understand its main event components; and generated query geography plus `mini concert` left context words as required identity terms. Native HTTP200 pages retained in local evidence reproduced unknown fields on the previous source. The same pages contain main event date/location icons and, when provided, a time icon.

A separate benchmark process ran only after discovery was sealed. A clearly synthetic matching-date collision demonstrated that an exact date alone could not repair the identity error. No expected date was inserted into discovery, and no corpus fact was changed.

## One Bangkok capability

The new dedicated parser supports only exact HTTPS `onebangkok.com` and `www.onebangkok.com`, with `/en/whats-happening/<safe-slug>/` or its Thai-language equivalent. Explicit ports, userinfo, foreign/subdomain/lookalike hosts, traversal/encoding/extra segments, transactional route names and unknown query parameters are rejected. Six standard UTM parameters and fragments are stripped. Existing same-host validated redirects, request/deadline/concurrency/cache/streaming/audit limits remain in force. This is hostname trust, not DNS address pinning.

A bounded, quote-aware tag stack requires a unique active head/main, matching canonical URL, event-content template, page title and main hero heading. Only main hero and main detail icon fields can provide date/time/venue. Latest-event cards, narrative/ticket-sale dates, opening hours, scripts, comments, templates, hidden/rawtext and select content cannot supply event components. A plaintext opener makes subsequent markup literal and fails closed. The official site's redundant unmatched closing anchor has one narrow compatibility rule that does not close or pop any component; other structural mismatches remain unknown.

Conflicting or invalid main dates stay unknown; an ambiguous date also prevents time hydration. Missing time stays null even when another event has a time in the same page. Date/identity/field conflicts preserve the original lead. One Bangkok pages that fail this dedicated boundary never fall back to a global date parser.

The follow-up helper removes only the proved generated geography suffix and `mini concert` phrase from query context. It does not alter title identity tokens. Named unrelated queries continue to perform zero detail reads. The public adapter advances to V12. SourceRegistry remains V8 and keeps its existing required universe.

## Known-miss identity

KnownMiss V12 requires distinctive alias identity words before any containment or fuzzy match. Whole-word forward containment replaces reverse substring matching. Adjacent split/joined whole names remain supported; substring fragments or separated fragments cannot satisfy a joined identity. Numeric group identifiers such as 127 and alphanumeric names such as 0WAVE remain meaningful. Generic format/location/date words cannot establish identity alone.

The 75% compatibility score is applied only after all distinctive alias words are present. The public normalization/token interfaces, all corpus entries and aliases, fixture evidence, date/source requirements and evaluator/classification semantics remain unchanged. No artist/event blacklist was introduced. Tests cover strict same-day synthetic wrong-artist rejection and shared consumers: reference alignment, production identity comparison and learning duplicate handling.
