## Immediate finding and repair

**P0 — internal operational notes leak from the public event CSV.** At 08:28 Bangkok, GET `/api/kk-data?sheet=08_Web_Ready&range=A4:K` returned HTTP 200 and exposed an `OWNER_HIDDEN` annotation plus an owner instruction in `event_note`. The affected FANIVAL 11 October row was still `hide`; the defect is public API disclosure, not evidence that the hidden card was reopened. The API reported 112 fields redacted, but this short token escaped.

Root cause: both sanitizers required at least two underscores. `OWNER_HIDDEN` contains one. The browser also lacked the server's pipe delimiter handling. The repair recognizes one-or-more underscores in both guards and aligns pipe boundaries. It preserves event identities, dates, prices, visibility and ordinary Thai/customer/device wording. Internal Sheet notes are retained. Tests reproduced two failures before the fix and pass 24/24 afterward. Independent reviewer approved source storage. **Production disclosure remains open until this exact patch is released and the endpoint is read back.**
