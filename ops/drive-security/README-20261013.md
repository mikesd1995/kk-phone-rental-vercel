## Failure/rollback policy

- Never use `share_file(reader,anyone_at_company=true)` as a substitute: that **adds** a company-domain grantee without removing existing public Writer.
- Never move, duplicate, make private or replace active poster files to manipulate permissions; this can break their source IDs and customer-facing links.
- Do not restore public Writer as a casual rollback. To recover a broken customer image, diagnose access via a signed-out browser and restore only safe public **Reader** access under owner control.
- This repair is a security remediation, not an opportunity to publish hidden events, alter photos, contact renters or run paid services.
